# koneps — 요구사항 명세

## 1. 사용자 역할

| 역할 | username 예시 | 권한 |
|---|---|---|
| 담당자 (manager) | `manager01~03` | 공고 수집·분석·위험도 검토·제안목차 생성 |
| 대표 (CEO) | `ceo01` | 입찰 현황 요약·KPI·전략 리포트 조회 (제한된 페이지만) |

## 2. 기능 요구사항

### FR-01. 공고 자동 수집
- 나라장터 OpenAPI에서 용역 공고 수집
- 매일 4회 자동 (10:00 / 13:00 / 16:00 / 20:00 KST)
- 서버 시작 시 마지막 슬롯 이후 빈틈 보정 수집
- 2단계 키워드 필터 (IT 컨설팅·ISP/ISMP 위주)
- 첨부파일 PDF/HWP/HWPX 자동 다운로드

### FR-02. 공고 목록·검색·필터
- 공고 목록 페이지(현황 리스트): 수집일/상태(전체·마감임박·위험공고) 필터
- 검색: 공고명/기관명/공고번호 부분일치 (즉시 드롭다운)
- 마감 지난 공고 제외 토글
- 찜한 공고 / 진행 프로젝트 분리 탭

### FR-03. AI 분석 (핵심)
- 분석 트리거: POST `/analysis/run/{bid_ntce_no}` → 백그라운드 실행
- 분석 결과: 정형(예산·기간·계약방법 등) + 평가항목·요구사항(JSONB) + 독소조항
- 위험도 4단계: safe / caution / warning / danger
- 독소조항 16개 체크리스트(S1~L4) + OTHER
- 각 독소조항: 코드 / 심각도 / 조항 원문 / 판단 근거 / 출처
- 분석 결과 페이지에 종합 위험도 + 카드 리스트 표시

### FR-04. 실시간 진행 로그
- 분석 중 progress_store에 누적되는 로그를 GET `/analysis/{bid_ntce_no}/status`로 폴링
- BidSlideOver / BidDetailPanel / AnalysisDetailPage에서 시간·등급별 색으로 흐름 표시

### FR-05. 제안목차 자동 생성
- ISP / ISMP / 기타 사업유형 판별 후 가이드라인 기반 목차 생성
- proposal_outlines.sections (JSONB)에 저장
- Excel 내보내기 (main / outline / requirements 3개 시트)

### FR-06. 담당자 대시보드
- 오늘 신규 공고 / 마감 임박 KPI
- 현황 리스트 + 대상 리스트 (찜 / 진행)
- 공고 유형 분석 (도넛)
- 마감일 캘린더

### FR-07. CEO 대시보드
- 진행 프로젝트 KPI / 위험 공고 비율
- 전략 리포트 (위험 공고 요약)
- 제한 페이지: 대시보드 / 진행 프로젝트 / 전략 리포트 / 설정 / 도움말

### FR-08. 공고별 메모 (담당자)
- notice_memos 테이블에 공고별 1개 메모
- 작성자(author_name) 표시

### FR-09. 찜 / 진행
- bookmark / in_progress 플래그 토글
- 진행 토글 시 자동 찜

### FR-10. 페이지 상태 persist
- 새로고침해도 마지막 페이지 + AI 분석 상세 화면 유지 (localStorage)

## 3. 비기능 요구사항

| 항목 | 요구 |
|---|---|
| 응답 시간 | 목록 < 1s, AI 분석은 30s~2분 (백그라운드 + 폴링) |
| 분석 첨부 캐시 | 수집 시 다운로드된 `local_path` 우선 사용 (G2B 재호출 최소화) |
| 외부 API 한도 | 리브레AI 일 50회 — 캐시·재시도 고려 |
| 데이터 신선도 | 현황 리스트 기본 필터 `전체` (수집일 매핑: `collected_at`) |
| 디자인 | Tailwind v4 + Radix UI + CSS 변수 (`var(--dash-*)`) 톤 유지 |
